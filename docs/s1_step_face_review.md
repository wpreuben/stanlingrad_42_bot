# S1 시작 카운터 단계 수 검수

[`s1_step_face_review.csv`](s1_step_face_review.csv)는 [`s1_counter_named_images.csv`](s1_counter_named_images.csv)의 171개 시작 카운터를 그대로 따라간 **중간 판독 자료**다. 규칙서 v2.1 §2.3.5는 3단계 부대의 뒷면을 가는 띠, 마지막 단계 면을 넓은 띠로 구별한다. 이미지의 `-f`/`-r` 파일명은 물리적 앞뒷면이며, 시작 카드가 항상 `-f` 면을 쓰지는 않는다.

두 면이 확인된 비사령부 126개에 대해 `-r` 이미지의 오른쪽 빈 부분(`x=73`, `y=28–47`)을 측정했다. `y=22,50`의 평균 RGB에서 유클리드 거리 50 초과인 픽셀 수가 0–7이면 가는 띠, 16–18이면 넓은 띠로 임시 판정했다. 중간값 8–15는 없었다. `GE-75Inf-Div-r.png`(가는 띠), `GE-385Inf-Div-r.png`(넓은 띠), 시작 카드에서 `-r` 면을 쓰는 `GE-23Pz-Div-r.png`를 확대해 이 해석을 표본 대조했다. 결과는 가는 띠 45개(최대 3단계), 넓은 띠 81개(최대 2단계)다. `provisional_stripe_measurement`는 개별 면 전수 육안 검수가 끝났다는 뜻이 아니다.

반대 면을 찾지 못한 35개는 **1단계로 추정하지 않았다**. 예를 들어 `GE-16Pzg-Div`의 다른 면 이미지는 아직 없지만, 시작 이미지의 붉은 점을 보아 단계 수를 단정할 수 없다. `CR-369Inf-Regt` 1개만 이름 붙은 빈 뒷면이 확인돼 1단계로 기록했다.

사령부 9개는 §18.2의 포병 지원 유닛이다. 준비/사용 면은 **각각 1단계인 상태 면**이므로 줄무늬 판정에서 제외했다. 시작 카드의 9개 모두 `-f` 준비 면으로 시작하며 `-r`은 사용 면이다. 엔진은 `UnitFace.state`, `Placement.face_state`, `UnitState.face_state`에 이 구별을 보존한다. `S(1)5`/`0(1)5`의 지원 효과 구현은 §18 규칙 단위에서 다룬다.

이 CSV는 아직 `units_s1.json`이 아니다. 실제 카탈로그 작성 전에는 누락된 다른 면, 병과·국적, 3단계 부대의 잔존 병력 연결, 시작 면과 단계 수를 확인해야 한다.
