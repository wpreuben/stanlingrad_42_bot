# Map A 일괄 판독 가능성 시험

목적은 이미지의 모든 헥스를 대화에서 하나씩 읽는 비용을 줄이는 것이다. VASSAL 모듈의 정확한 격자로 위치를 일괄 생성하고, 로컬 프로그램이 픽셀을 판독한 뒤 신뢰할 수 없는 곳만 검수하는 방식을 시험했다. 이번 시험은 **자동 지도를 완성한 결과가 아니라** 기존 검수 자료에 대한 탐지력 조사다.

## 자료와 방법

- 입력: Map A 3300×5100 JPEG, VASSAL Map A 헥스 격자(`dx≈98.855`, `dy≈113.9`), 현재 검수된 변 178개와 헥스 80개.
- 변의 중점 주변 29×29픽셀에서 파란색(강), 붉은색(도로 가능성), 어두운색(철도·주요도로 가능성) 픽셀 수를 세었다.
- 같은 검수 자료로 신호를 살펴본 **훈련 자료 내부 수치**다. 독립 검증 성능이나 지도 전체 정확도로 해석하면 안 된다.
- `tools.map_edge_pixel_candidates`가 지금까지 확인한 인쇄 헥스 ID 사이의 기하학적 변 후보 2,947개를 일괄 점수화해 `map_a_edge_pixel_candidates.csv`를 만든다. 아직 확인하지 않은 지도 영역의 변은 이 수에 포함되지 않는다. `signals`는 검토 순서를 위한 후보명이고 확정된 강·도로·철도 속성이 아니다.

| 신호 기준 | 실제 대상 | 찾음 | 잘못 표시 | 놓침 | 판정 |
|---|---|---:|---:|---:|---|
| 파란 픽셀 ≥25 | 강 28변 | 25 | 0 | 3 | 강 검토 순서에 유용하지만 확정 자료로는 불완전 |
| 붉은 픽셀 ≥5 | 보조도로 24변 | 22 | 38 | 2 | 글자·다른 기호와 겹쳐 단독 분류에 부적합 |
| 어두운 픽셀 ≥10 | 철도 또는 주요도로 13변 | 12 | 18 | 1 | 두 종류를 서로 구분하지 못하고 다른 표식도 잡음 |
| 51×51 영역의 파랑·붉음·어두움 합계 ≤10 | 특성 없음 113변 | 85 | 0 | 28 | 검수 구역에서는 오류가 없었으나 지도 전체 검증 필요 |

강을 놓친 변은 `1502→1602`, `1702→1802`, `1902→2002`다. 작은 중앙 창 대신 전체 헥스 변을 훑으면 세 곳의 파란 픽셀이 보이지만, 이 경우 강이 아닌 변도 31개 표시됐다. 따라서 검사 창을 단순히 넓히는 것만으로 해결되지 않는다.

미검수 변 2,769개 중 자동 신호가 표시된 수는 강 495개, 도로 1,154개, 철도/주요도로 461개다. 서로 겹칠 수 있다. 더 넓은 51×51 영역에 색 신호가 거의 없는 **특성 없음 후보는 1,135개**다. 이들은 후보이며 확정 자료가 아니다. 고정 시드 `420203`으로 이 중 임의 추출한 18개를 검토 시트로 육안 대조했을 때 원 안의 공유 변을 건너는 특성은 보이지 않았다. 이 작은 표본도 전체 오류율의 보증은 아니다.

현재 검수된 헥스 80개는 **모두 `clear`**다. 다른 지형의 표본이 없어 지형 분류기의 오류율을 측정할 수 없다. 이 상태에서 모든 헥스를 `clear`로 자동 확정하는 것은 검증이 아니다.

## 결정과 다음 시험

1. 현재의 단순 색 기준은 검토 우선순위에만 사용하고, 실행용 지도에 자동 확정값으로 넣지 않는다.
2. 다음 시험은 변 중점의 사각형보다 긴 선의 연결성·방향·질감을 이용해 도로·철도를 추적한다. 지도 전체를 한 번 처리하는 오프라인 도구로 구현하고, 검수 구역을 분리해 성능을 측정한다.
3. 지형은 종류가 다양한 소수의 표본을 먼저 검수한다. 분리한 표본에서 정확도가 확인된 종류만 자동 확정하고 나머지는 `unresolved`로 남긴다.
4. 출판사의 편집 가능한 벡터 지도 또는 헥스별 원천 데이터가 확보된다면, 이 이미지 판독보다 우선 조사한다. 제공된 VASSAL 2.03 모듈에는 그 자료가 없었다.

사용자가 추가로 해야 할 일은 없다. 편집 가능한 원본 지도가 이미 있다면 제공 시 작업량을 크게 줄일 가능성이 있지만, 현 자료만으로도 위 시험을 진행할 수 있다.

## 헥스 지형 색상 후보

`tools.map_hex_pixel_candidates`는 지금까지 확인한 인쇄 ID 1,042개의 중앙 61×71픽셀을 샘플링해 [헥스 후보](map_a_hex_pixel_candidates.csv)를 만든다. 중앙값 색상과 초록색·어두운색·파란색 비율로만 분류하므로 `candidate`는 지형의 확정값이 아니다.

| 후보 | 수 | 확인 상태 |
|---|---:|---|
| `clear_candidate` | 967 | 기존 평지 검수 80/80 포함. 별도 난수 표본 24개를 확대 대조한 결과 모두 평지로 판독. |
| `vegetation_candidate` | 32 | 난수 표본 12개를 확대 대조한 결과 모두 수목으로 판독. 수목과 수목 있는 험지를 자동 구분한 결과는 아님. |
| `marsh_candidate` | 2 | 습지 색상 후보. 일반 습지와 계절성 습지는 아직 구분하지 않음. |
| `major_city_candidate` | 3 | 대도시 색상 후보. |
| `unresolved` | 38 | 소도시, 해안, 요새 인쇄, 습지, 엔트리 구역 등이 혼합됨. |

표본은 각 후보 집합에서 `random.sample`을 사용해 시드 `420204`(평지), `420205`(수목)로 골랐다. 표본을 모델 개발 과정에서 살펴봤으므로 독립된 최종 정확도 인증은 아니다. [영문 규칙서 §2.2](https://gmtwebsiteassets.s3.us-west-2.amazonaws.com/Stalingrad42/Stal42_RULES-2025-Final_LoRes.pdf)는 도시가 아래 지형을 덮어쓰고, 산지가 일부라도 있는 헥스를 산지로 취급한다고 명시한다. 따라서 중앙색만 평지인 경우 산지 조각 같은 예외를 놓칠 수 있다. 현재 도구는 Map A 후보 검토에만 사용하고 플레이용 지도로 승격하지 않는다.

헥스 후보 재생성 명령:

```bash
uv run --locked --group map-tools python -m tools.map_hex_pixel_candidates \
  '../../images_high/Stal42_Map_west-FINAL-150 Q12.jpg' \
  --output docs/map_a_hex_pixel_candidates.csv
```

후보 파일 재생성 명령:

```bash
uv run --locked --group map-tools python -m tools.map_edge_pixel_candidates \
  '../../images_high/Stal42_Map_west-FINAL-150 Q12.jpg' \
  --output docs/map_a_edge_pixel_candidates.csv
```
